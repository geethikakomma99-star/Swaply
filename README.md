# Swaply - C2C Exchange App Case Study

Swaply is a mobile marketplace application that connects local users to list, purchase, or swap second-hand and new items (such as electronics, furniture, and vehicles) directly through the internet.

## ✨ Key Features & Catalog
- **Curated Resale Feed:** Features popular local items including the Nothing Phone 2a, Pink Jupiter Scooty, Sofa Set, Bullet Bikes, and academic books.
- **Transparent Pricing:** Evaluates second-hand resale savings against original market prices.
- **Interactive Modals:** Tap product cards to inspect item details seamlessly.
- **Smart Navigation:** Quick access to home feeds, alerts, user history, and profile management.

## 📱 Tech & Design Stack
- Designed and prototyped in **Figma** using mobile-first layout patterns and interactive micro-interactions.
